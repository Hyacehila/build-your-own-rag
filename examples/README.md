## 组织方式

每个示例放在 `examples/<example-slug>/`，使用小写英文和短横线命名，包含 `README.md`、源代码、依赖清单和必要配置。示例使用 `uv` 独立管理 Python 版本、环境和依赖，尽量少依赖现成的 RAG 框架或系统。

示例的 README 或链接文档应说明：

- 解决的问题、相关教程、输入输出、实现思路，以及依赖的用途和选择理由。
- 操作系统、Python 版本、硬件、依赖安装、配置、启动步骤和预期结果。使用远程或收费服务时，说明账号要求及可能产生费用的步骤。
- 使用数据集时，说明上游来源、版本、许可、下载链接及准备方式。
- 实际验证的环境、命令、结果和已知限制；未验证的内容如实说明，必要时记录验证日期。

仓库不单独发布数据集。真实 API 密钥保存在本地环境变量或 `.env` 中，仓库只提交脱敏的 `.env.example`。索引、缓存和输出放在 `.local/`、`outputs/` 等忽略目录，模型权重放在 `model_weights/`，不随源码提交。
