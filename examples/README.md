## 组织方式

每个示例放在 `examples/<example-slug>/`，使用小写英文短横线命名。复制[示例说明模板](../templates/example-readme.md)作为该目录的 `README.md`，源代码、依赖清单和必要配置放在同一项目内。

说明中应包含：

- 示例要解决的问题、对应教程、实现思路及技术选择的理由。
- 操作系统、Python 版本、硬件与外部服务要求。
- 独立的依赖安装方式和经验证的版本。
- 配置项、数据准备、启动步骤和预期结果。
- 实际验证的环境、命令、结果及已知限制。

当前骨架不指定统一的包管理工具。示例尽量少依赖现成的 RAG 框架或系统；确有需要时，说明依赖解决的问题和选择依据。新增示例须确定一种可复现的运行方式，并记录实际使用的版本；不同示例的依赖互不要求兼容。

真实 API 密钥保存在本地环境变量或 `.env` 中，仓库只提交脱敏的 `.env.example`。运行产生的索引、缓存和输出使用忽略规则覆盖的目录，例如 `.local/` 或 `outputs/`。模型权重放入 `model_weights/`，不随示例源码提交。

共享数据统一从[数据集目录](../datasets/README.md)引用，不在多个示例中重复存储。依赖远程模型或收费服务时，说明运行所需账号、配置以及可能产生费用的步骤。
