这里存放各章节引用的项目代码，供读者理解实现并动手改写。教程正文讨论问题、原理与方案，完整实现集中在示例中。每个示例独立管理环境和依赖，可关联多个主线章节或加更。

示例主要使用 Python，以原生实现为主，按需引入依赖。读者可以借助 Coding Agent 将其改写成其他语言，再根据示例的输入、预期输出与验证方法检查结果。示例提供必要的运行信息，不承诺逐行讲解或覆盖所有环境的报错。

## 组织方式

每个示例放在 `examples/<example-slug>/`，使用小写英文短横线命名。示例目录包含 `README.md`、源代码、依赖清单和必要配置。

示例说明按实际需要组织，可以从 `README.md` 链接到项目内的其他文档。应说明：

- 示例要解决的问题、对应教程、输入输出、适用范围、实现思路及技术选择的理由。
- 操作系统、Python 版本、硬件与外部服务要求。
- 独立的依赖安装方式和经验证的版本。
- 配置项的用途、必需项或默认值，数据准备、启动步骤、预期结果及输出位置。
- 实际验证的环境、命令、结果及已知限制；必要时记录验证日期，未验证的内容如实注明。

仓库不指定统一的包管理工具。示例尽量少依赖现成的 RAG 框架或系统；确有需要时，说明依赖解决的问题和选择依据。新增示例须确定一种可复现的运行方式，并记录实际使用的版本；不同示例的依赖互不要求兼容。

真实 API 密钥保存在本地环境变量或 `.env` 中，仓库只提交脱敏的 `.env.example`。运行产生的索引、缓存和输出使用忽略规则覆盖的目录，例如 `.local/` 或 `outputs/`。模型权重放入 `model_weights/`，不随示例源码提交。

示例使用开源数据集时，在对应示例中提供上游来源、版本、许可、下载链接及必要的数据准备步骤；仓库不单独发布数据集。依赖远程模型或收费服务时，说明运行所需账号、配置以及可能产生费用的步骤。
