# 最终标题树审阅与成本边界

对象是生成的标题树，包含主文档、附件和容器内标题，不要求阅读每个正文节点。使用目录和标题语义判断，源页只用于局部取证。自动校验只能证明覆盖/版本/指定关系一致，不能证明 Agent 真的读过材料或全部语义正确。

## 证据准备

脚本提供连续的紧凑标题包：ref、原文标题、物理页、级别、父标题、祖先 ref、兄弟顺序和所属范围。祖先文本用映射按需查询，避免每个节点重复打印整条长路径。包应提供跨包父节点上下文，按材料长度分包，不截断一个标题及其定位信息。

不要将完整 Docling JSON、表格 Markdown、正文列表或冗长工具日志发给审阅 Agent。本地脚本处理这些数据，仅返回与标题判断相关的结果。没有目录时记录原因；没有标题时区分真实平坦文档与漏识别，保留有证据的空树说明，不创建虚假标题通过验收。

代表页只选标题样式、章节起点或附件边界。查看图像前确定定位目的，优先提供标题附近裁剪及必要短上下文；目录页可整页读取。跨栏归属疑问可看整页版面，不扩展为逐页正文阅读。实际看过的图像页与只提取原生文字的页面分别记录。

## 审阅顺序

1. 阅读真实目录及书签候选，核对物理页。目录可能省略小标题或印错页码，不能当成绝对真值。纯导航可排除，混合页保留正文。
2. 连续检查全部生成标题分支，结合父子语义、相邻兄弟、编号序列、字体和附件边界。平坦结构可以正确，不为增加深度推断父节点。
3. 标记异常及影响范围。例如同级国家嵌入另一国家、`I/V/X` 字母被当罗马数字、表题或签名吞并正文、目录被当章节、普通组中的标题未进入标题栈。异常定位到 ref 和页号。
4. 对异常查看标题原页证据，用受支持操作局部修正。需要大段正文才能判断时记录歧义，明确扩大审查的代价，不自行开展全文 Agent 审查。融合/缺失标题或不支持的变换保留问题，不凭语义补写文本。
5. 重放后比较标题集合、文字、页面、顺序、直接父标题和全部祖先。复核所有改变分支及后续兄弟，直到真实章节边界；容器修复可能影响全局，按实际差异扩大范围。未变且已审分支可复用记录；新增/未审标题不能通过哈希比较补齐审阅。
6. 在最终候选验证预期关系，签署绑定该快照的回执。后续事实修改需重新绑定并复核差异。已确认错误、覆盖缺失或引用失效时不签通过；真正不确定的项目保留明确原因。

## 通用审阅记录

以下描述记录的语义，不强制某个项目的字段名称。草稿通常使用 raw ref；最终记录必须使用实际最终快照 ref，通过排除/重映射记录转换，不能猜测引用对应关系。

| 字段 | 要求 |
|---|---|
| 文档身份、审阅协议、最终快照与树哈希 | 必须精确绑定实际被审阅的候选；不要求数据库 parse ID |
| `reviewer`, `final_tree_reviewed` | 真实审阅者及完成声明，不由扫描代签 |
| `reviewed_heading_refs` | 最终标题各一次，包括容器/图片内标题 |
| `contents_pages_viewed`, `representative_pages_viewed`, `suspicious_pages_viewed` | 真正查看的物理页；无目录提供 no_contents_reason；代表页聚焦标题 |
| `expected_relations` | 每项含 child_ref、relation、expected_parent_ref、evidence_pages；覆盖修复、受影响兄弟及代表性未变边界 |
| `confirmed_wrong_parent_remaining` | 通过时为空，不把确认错误移到不确定列表放行 |
| `uncertain_exceptions` | 未决原因、范围和下一步，未决不代表正确 |

预期关系可以检查直接父节点或最近父标题，顶级标题的父标题可以为空。另保存包哈希、分支复用依据、变更记录、局部读取原因和成本。实现时区分工具实际验证的字段与需要审阅者履行的行为，不能把前者当作后者的证明。

## 发布检查

所有交付为完成状态的文档都要完成审阅，不固定为六份。文件级验收应拒绝过期快照、漏审/重复/外来 ref、不满足的预期关系及已确认错误；不要求数据库发布器。来源几何、正文/表格质量和标题语义是不同验收维度，均须报告，不能互相替代。

当前项目的回执适配与零标题限制见 [项目适配](project-adapter.md)，不把该实现限制当成通用清洗要求。完整标题树审阅不覆盖正文每个字符、所有表格单元格或图片文字；缺失标题另用目录、样式候选和局部原页检查定位。
