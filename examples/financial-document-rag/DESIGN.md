# 当前金融文档 RAG 实验契约

五个实验组统一命名为 A、B、C、pre-D、D；检索数量、读取预算和运行批次分别记录，不编码进组名。本文规定检索、原文装配、回答和评分的边界；参数由 `config.toml` 管理。当前结果包含新生成的296题A/B/C及原批次D/pre-D复用，批次在报告中分别标明。

## ABC原文优先方案：BC-source-priority-v3

共同使用同一个原问题、RRF20、稀疏/向量各50候选、稳定ID打破同分；无重排器、无公司硬过滤、无新模型规划/查询改写。保持原始800 token切片、100重叠、源库/索引/摘要和标签不变。

- A：flat_final_k=10，保留原来的来源分组及原文装配，不扩展上下文；预期读取约7–8k而非强制填满8k。共同text_tokens=40000只是原有上限，不用于填充。
- B：原始B索引，按原始版本/节点/资产/跨度去重补位，最多20入口。
- C：首先在B原始索引执行与B完全相同的选择；再对同一查询检索enriched索引，仅从其中摘要候选选最多5个具有新增基础覆盖的入口。全覆盖摘要跳过，部分重叠保留新增，候选耗尽允许不足5。原始20入口不会被摘要替换。是一次固定查询阶段的两次索引查询，共享同一查询向量缓存；不是一次物理索引查找，也不调用第二次回答模型。摘要选用该enriched索引原有RRF排名，不新增摘要独立语料BM25或重建索引。
- C装配先完整尝试B基础锚点和必要关联，再装配摘要映射的全部成员；预算不足明确记录未读成员。摘要不能挤掉B基础锚点，但可能挤掉B后续扩展，因此不保证C的25k包含B全部证据。
- 关闭summary_supplement_k时，C与B相同原始集合的证据装配须完全相同。

B/C共同上限25k估计原文、8图，不填满、不预留阶段配额；六阶段固定顺序：

1. 所有基础锚点与必要caption/脚注/表头；原始入口优先于摘要补充。
2. 可唯一解析的明确原文关系、结构关系及其关联具体小节。只从最初锚点触发；明确关联短节≤4k全读，长节前8直属正文及图表。
3. 同小节前后各8正文节点、正文≤4k短节完整读；窗口大小保持不变。
4. 最近一级父标题的直属总览，仅父标题到首个子标题前的内容，不读整个父节子树。
5. 同父节相邻小节跨标题±8正文节点，与已读范围合并，不递归。
6. 受控来源页最后补全，最多4k新增且服从25k总额，仅原始图表、多页绑定续接和明确结构缺口。没有普通单页正文默认整页、默认邻页或纯问题词匹配标题扩展。

每题保留两路排名、原始搜索与摘要补充日志、基础跨度、去重/补位、候选和已读范围、阶段新增量、图像、未读/截断与不确定重叠。摘要5043正文窗口/1700图表摘要复用，摘要文本不作为证据。B/C共同SYSTEM、一次回答和评分契约不变。

## D与pre-D边界

首次模型调用仅根据问题改写查询和请求项，检索B原始索引。首次共享快照仍只含原始锚点及关联说明/图像，不含D新扩展，不允许覆盖。pre-D在D结束后使用这个快照和共同SYSTEM回答，其结果不进入D。

D在共享快照保存后自动进行固定扩展，无额外模型规划调用：同一具体小节前后各8正文节点、短小节完整读、图表及明确关联说明。随后由模型围绕缺口补查并读原文。它不设置最低token或最低补查次数，但提示明确要求比较缺一方、定义/单位/期间/净额冲突、列表或续表不完整时改写查询，读取新锚点；不能把搜索片段当作已读证据，不能因局部没找到就断言文档没有。

工具只有search、read、read_parent、read_source_pages、continue_read、read_evidence。普通read只选原始source_ids，由程序固定窗口，不再让模型填写mode/radius/depth。read_parent沿原始parent_id查找上级标题，读取其完整原始子树（含各子节），允许越过具体小节边界；没有真实父标题时明确返回不能上溯，不默认读取整文档。read_source_pages读取锚点sources绑定的原页，含绑定的跨页续表，不进行全库标题加页或无来源邻页猜测。来源身份始终限定B原始索引，不允许读取C摘要。

较长选定范围按服务请求容量分批，返回不可伪造的续读游标；每一逻辑响应的多个工具共享本次传输余量，完整范围留在原文库可继续读。此余量从真实上下文减输出/提示/工具开销推导，另预留容纳工具元数据及计数误差的空间，不是累计读取上限；不自动凑满窗口，也不限制整题累计原文。工具返回新增证据与未完范围，完整节点选择保留在本地trace，模型接收精简的来源和续读信息。

D输出使用明确的answer和字符串ID citations示例。对象式引用可无模型归一化；自然语言最终正文也可提取，未知ID仍保留为引用错误，不能当有效来源。coverage为可选诊断，缺失或格式问题不阻断有效正文；judge仍只接收answer。工具参数错误反馈到下一逻辑轮次，不重放工具或反复执行物理格式重试。空/不可解析的正文仍需要修复；已有效答案不因原评分判错而补跑。A/B/C/pre-D原输出校验与共同SYSTEM保持不变。

D每次执行最多24次探索逻辑调用（包含未缓存的首次改写）及必要时第25次关闭工具回答。无最低阅读量；累计16不同原图、单请求8图。2026-10-07合成输入验证得到网关错误元数据：实际最大上下文131072，输出预留16384。此前100万是用户声明且与服务不符，新版不得继续作为真实上限。文本使用cl100k_base、图像使用序列化代理计数，加入显式计数安全系数，仍不是提供商tokenizer或图像计费的独立认证。

每个物理重试也要先容量检查。若遇input_tokens HTTP400，保存只含数字的容量诊断，在同一逻辑调用内最多以不同的压缩请求再试一次；再次失败即按执行失败处理，不重复提交已知超限的相同body。原文在证据库保存，可通过read_evidence再展示，压缩/图像省略显式记录。

B→C仍检验摘要入口；pre-D→D比较固定首轮扩展与后续主动回查的联合效果；B→pre-D包含查询和初始装配差异。D的当前工具、输出和容量规则维持已验收版本；不得把固定首扩展与主动补读的联合收益归因单一参数。

## 执行与汇报

`experiments/a.py`、`b.py`、`c.py`、`pre_d.py`、`d.py`是五个独立编排模块，统一支持`--plan`。公共执行器负责身份、失败恢复和记录；共同评分只消费本次生成的组别。pre-D独立入口必须提供完整既有D快照，不隐式运行D。

本次仅ABC全量296题，每组296条新答案。D/pre-D从独立复用材料读取原记录和原评分，不调用生成或judge；D193保留原四次尝试耗尽零分。原run_id和原记录哈希保持，来源标记在汇总层添加。

首次执行全部新题后统一补跑无有效答案者最多3轮；有效答案即使判错也不再生成。固定296分母，只发布统一终态。SQLite/WAL续跑保护成功答案和judge缓存，不多耗补跑轮。冻结源码、配置、模型、提示、原题/标签、索引和API起始边界后不修改。

全部题历史结果曾被观察，不称盲测；49及历史76开发范围继续披露，不改标签制造排名。ABC与历史D/pre-D是不同运行批次，时间差异及多项策略差异限制因果解释。A 组本轮减少检索入口后的排名变化不单独证明 B/C 自身提高。来源绑定、成功执行、读量和准确率分开判断。

新ABC核查评分完成后才切换最终交付指针。新增费用与历史复用费用分开，未知用量不记零；报告保留逐题来源、配对得失、预算及评分争议。

## 校验边界

验收依据结构、范围、来源关系、文件可读性、成功记录保护和 SQLite/WAL 检查。既有内容 ID、缓存键与去重键保持兼容。
