# 原创教学夹具

[返回示例说明](../README.md)

[product-review.md](product-review.md) 是为第一章编写的虚构产品复盘。产品、实验、日期与数值均为演示用途。

这份输入包含两个同名的“观察结果”小节、列表、四列表格、图片引用和图注，用于检查标题归属、阅读顺序及元素关系。图片地址使用不可访问的演示域名 `example.invalid`；示例只保留地址和替代文字，不下载或生成图片。Markdown 的替代文字在此被明确用作演示图注，其转换方式见示例说明。
