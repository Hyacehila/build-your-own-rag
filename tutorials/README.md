# 教程组织与写作约定

[返回项目首页](../README.md) · [项目理念](../README.md#项目理念) · [贡献指南](../CONTRIBUTING.md)

正式内容分为[主线教程](main/README.md)与[特别加更](extras/README.md)。当前两类均尚未发布；写作从模板开始，模板不作为正式章节展示。

主线以真实项目和问题为导向，覆盖从数据清洗到评测的流程，并按场景需要补充工程知识。加更可讨论独立问题、实验或与主线无关的话题，不要求每篇都依附某个主线章节。

## 目录与编号

主线使用 `main/001-topic-slug/`，加更使用 `extras/ex001-topic-slug/`。这里的路径仅为命名示意，不表示已经存在相应章节。两类独立递增编号，发布后的编号和目录名保持稳定；加更不插入主线编号。

每章使用以下布局，按需创建实际文件：

```text
<chapter-directory>/
  README.md       中文正文
  README.en.md    英文译文（完成后添加）
  assets/         本章共享图片等资源（需要时添加）
```

目录名使用小写英文、数字和短横线，标题可使用中文。文章先后顺序由目录与导航表达；如后续调整学习顺序，更新目录与导航，保留已发布路径。

## 开始写一章

1. 主线复制[中文章节模板](../templates/chapter.zh.md)，加更复制[中文加更模板](../templates/extra.zh.md)，放入新章节目录并命名为 `README.md`。
2. 替换模板中的方括号占位文字，补充具体场景、方案权衡、引用和实践任务；没有内容的可选部分可删除。
3. 添加需要的图片，并使用相对路径引用。第三方图片就近注明来源、作者、许可及修改情况。
4. 将导航中的纯文本提示替换为目标位置有效的 Markdown 链接。
5. 检查正文后，将章节加入[中文总目录](../README.md#主线教程目录)、[英文总目录](../README.en.md#main-tutorials)中的对应区块，以及[主线](main/README.md)或[加更](extras/README.md)索引；草稿或计划只写状态，不创建正文链接。

## 双语支持

中文正文没有译文时显示“简体中文 | 英文译文待补充”，不提前创建英文空文件。

译文完成后，中文正文头部使用 `简体中文 | [English](README.en.md)`；英文正文使用 `[简体中文](README.md) | English`。相关文件只有在实际存在时才可链接。

英文译文可分别从[英文章节模板](../templates/chapter.en.md)或[英文加更模板](../templates/extra.en.md)开始。译文须记录对应中文原文的版本：优先使用包含中文内容的 Git commit；若与中文首次同时提交，可使用明确的中文修订标识或版本日期。另记录最后同步日期，采用 `YYYY-MM-DD`。元数据必须反映实际同步情况。

英文总目录包含所有已发布章节。有译文时链接译文；没有译文时链接中文并标注 `Chinese only`。中文发生实质变化而英文未同步时，英文正文和英文目录均标注 `Translation needs update`，保留原有源版本及同步日期，完成同步后再更新。

## 导航与目录维护

- 主线正文提供上一章、返回总目录、下一章；首章和末章的缺失方向使用“无”或 `None`，不生成空链接。
- 加更正文说明前置知识，有相关主线时添加链接，无关联时注明独立话题；提供返回总目录，不强制设置上一篇、下一篇。
- 中文正文返回根目录 `README.md`，英文正文返回根目录 `README.en.md`。在既定章节目录深度下，它们的相对路径分别为 `../../../README.md` 和 `../../../README.en.md`。
- 英文章节导航优先链接相邻章节的英文版本；只有中文时标注 `Chinese only` 并链接中文版本。
- 根目录[中文 README](../README.md) 和[英文 README](../README.en.md) 是读者的完整总目录，分类索引同步维护。主线按推荐学习顺序排列，加更按编号排列。
- 新增或改变章节顺序时，同时更新受影响的相邻章节导航。

正式章节的目录条目采用“编号 + 标题 + 正文链接”；只有在章节发布后添加条目。模板、空目录和计划说明不算已发布章节。

## 内容与验证

每章从具体问题出发，说明学习目标、前置知识、输入和约束，再解释原理、技术选择与权衡。必要时对比替代方案，明确哪些选择来自场景要求，哪些来自作者偏好。

正文保持与具体编程语言无关，不嵌入具体代码，也不逐行讲解实现或罗列安装、排错步骤。可以用文字、流程图和表格解释方案；实践部分提出读者需要完成的任务、应观察的现象及验证方法。

具体代码放在[示例项目](../examples/README.md)，数据放在[数据集目录](../datasets/README.md)，文章通过相对链接关联。示例以原生实现为主，按需引入依赖，并在各自说明中保留必要的运行和验证信息。数据和代码不因英文翻译而复制一份。

读者可以自行实现，也可以借助 Coding Agent 改写示例，随后验证结果。文章只记录实际执行过的结果，区分预期表现、观察结果与推测。

发布前检查目录、正文、图片、语言切换和导航，并确认引用及[许可说明](../LICENSING.md)完整。
