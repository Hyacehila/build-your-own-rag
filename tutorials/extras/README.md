# 特别加更

[返回加更总目录](../../README.md#特别加更目录) · [主线教程](../main/README.md) · [写作约定](../README.md)

加更用于独立的问题讨论、实验或补充说明，也可以聊与主线无关的话题。每篇说明前置知识；与主线有关时附上对应链接，无关时注明独立话题，便于读者判断何时阅读。

正文同样以问题与思路为主，可以用短 JSON、文档树等解释数据结构；实现代码和运行命令放在[示例项目](../../examples/README.md)中。共享数据链接[数据集](../../datasets/README.md)，示例自带的原创教学夹具链接其说明。

## 新增加更

从[中文加更模板](../../templates/extra.zh.md)开始，使用 `ex001-topic-slug` 形式的目录名，中文正文命名为 `README.md`。英文译文完成后再加入同目录的 `README.en.md`。

发布时同步本页、[中文加更目录](../../README.md#特别加更目录)和[英文加更目录](../../README.en.md#extra-chapters)。加更按独立编号排列，不改变主线编号，也不要求连续阅读。
