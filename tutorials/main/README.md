# 主线教程

[返回主线总目录](../../README.md#主线教程目录) · [特别加更](../extras/README.md) · [写作约定](../README.md)

主线面向有编程基础的读者，从真实项目和问题出发，讨论从数据清洗到评测的方案与权衡，并按需补充工程知识。具体的知识要求会在每章开头说明。

正文不嵌入具体代码，以通用的技术问题和解决方案为主；具体实现放在[示例项目](../../examples/README.md)，相关数据见[数据集](../../datasets/README.md)。读者可以参考 Python 示例，也可以借助 Coding Agent 用自己熟悉的语言实现和验证。
