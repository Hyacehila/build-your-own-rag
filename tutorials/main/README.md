# 主线教程

[返回主线总目录](../../README.md#主线教程目录) · [特别加更](../extras/README.md) · [写作约定](../README.md)

主线面向有编程基础的读者，从真实项目和问题出发，讨论从数据清洗到评测的方案与权衡，并按需补充工程知识。具体的知识要求会在每章开头说明。

正文以通用的技术问题和解决方案为主，可以展示短 JSON、文档树等数据结构示意；具体实现和运行命令放在[示例项目](../../examples/README.md)，共享数据见[数据集](../../datasets/README.md)。示例也可以自带原创教学夹具。读者可以参考 Python 示例，也可以借助 Coding Agent 用自己熟悉的语言实现和验证。

## 已发布章节

主线从数据清洗起步，第一章先确定希望保存的目标数据格式，再为后续解析与清洗工作建立判断标准。

- [001 · 什么样的数据格式，适合成为 RAG 的事实层？](001-document-format/README.md)：保留文档结构、明确事实层边界，并通过独立示例检查保存与回读。
